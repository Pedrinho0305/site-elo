COMO DEIXAR SO O JOGO NA PAGINA (sem a interface do gd.games)
=============================================================

A pagina pages/jogo.html tenta primeiro abrir o jogo desta pasta. Se nao
existir, ela usa a pagina do gd.games, que vem com o menu e os anuncios
deles (o gd.games nao permite embutir so o jogo).

Passo a passo no GDevelop (quem publicou: Guilherme):

  1. Abra o projeto no GDevelop.
  2. Menu  Arquivo > Exportar  (ou o botao "Publicar").
  3. Escolha  "Web (HTML5)"  >  "Exportar para uma pasta local".
  4. Exporte para uma pasta qualquer (ex.: Area de Trabalho/jogo-elo).
  5. Copie TODO o conteudo dessa pasta para ca (backend/../jogo), de modo
     que fique  jogo/index.html  ao lado deste LEIA-ME.
  6. Abra pages/jogo.html: o jogo aparece sozinho, sem interface externa.

Republicou o jogo? Repita os passos e substitua os arquivos.

Link atual do gd.games (usado so como reserva):
  https://gd.games/games/15184de8-d773-4b90-b41d-5c0a2c104402
Para trocar o reserva, edite data-fallback do iframe em pages/jogo.html.
