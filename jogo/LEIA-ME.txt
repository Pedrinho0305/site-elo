COMO DEIXAR SO O JOGO NA PAGINA (sem a interface do gd.games)
=============================================================

A pagina pages/jogo.html tenta primeiro abrir o jogo desta pasta. Se nao
existir, ela usa a pagina do gd.games, que vem com o menu e os anuncios
deles (o gd.games nao permite embutir so o jogo).

Passo a passo no GDevelop (quem publicou: Guilherme):

  1. Abra o projeto no GDevelop.
  2. Menu  Arquivo > Exportar  (ou o botao "Publicar").
  3. Escolha  "Web (HTML5)"  >  "Exportar para uma pasta local".
  4. Exporte para uma pasta qualquer (ex.: Area de Trabalho/jogo-elo).
  5. Copie TODO o conteudo dessa pasta para ca (backend/../jogo), de modo
     que fique  jogo/index.html  ao lado deste LEIA-ME.
  6. Abra pages/jogo.html: o jogo aparece sozinho, sem interface externa.

Exportou para Windows (pasta com Tcc.exe, .dll, resources/app.asar)?
Nao copie essa pasta para ca. O jogo HTML5 esta dentro do app.asar, na
pasta "app": extraia (npx @electron/asar extract app.asar saida) e copie
o conteudo de saida/app para ca.

Recebeu so o instalador (ex.: TCC-JOGO-PC_MOBILE - V3 -1_0_0-windows.exe)?
Ele e um pacote NSIS: abra com o 7-Zip (ou: npx 7zip-bin ... x arquivo.exe),
pegue resources/app.asar e siga o passo acima. Foi assim que a versao
atual (V3, PC e celular) entrou aqui. O .exe fica fora do git (264 MB).

DEPOIS DE COPIAR (obrigatorio): abra jogo/index.html e, logo abaixo da
linha  <script src="data.js" crossorigin="anonymous"></script>, coloque

	<script src="modo-elo.js"></script>

Sem ela o jogo volta a abrir na tela "PC ou Celular". Com ela, o site
escolhe sozinho: computador = modo PC, celular/tablet = modo celular
(variavel global VarModo do jogo; comeca direto na cena Inicio-Jogo).
Nao apague o modo-elo.js ao substituir os arquivos.

Republicou o jogo? Repita os passos e substitua os arquivos.
